# ASSIMTI Essowèréou Charles

> Network and cybersecurity engineer in Lomé, Togo. I build security tools and the communities that use them.

## What I do now

Since 2024 I have worked as a network and cybersecurity engineer at a petroleum company in Togo. I administer Active Directory and the site-to-site VPNs, centralize security logs in an XDR console, automate recurring network tasks and run internal penetration tests on the company's web applications. I am also finishing a Master's in Cybersecurity at IPNET Institute.

## What I build

I started building before I knew it was a job. In high school I made a website from my phone so students could download past exam papers. Today the work is more technical:

- **[APAST](/posts/apast-siem-deployment/)**, an intrusion detection setup with real-time Telegram alerts, built from open-source tools so a small team can afford it.
- **[PCAP Analyzer](https://github.com/en2eav0r/PCAP-Analyzer)**, a Python tool that turns a packet capture into a readable report of streams, queries and leaked secrets.

The [Projects](/projects/) page says for each one what I did myself and what is still missing.

What keeps me building is simple. Most organizations around me can't pay for security products made elsewhere, so somebody here has to make tools they can afford and run. I want to learn how to turn that into a business.
